# MegaSupply

Sistema de gestión de inventario con identificación por código QR e inteligencia artificial para empresas comercializadoras. Proyecto de Ingeniería de Software — Universidad Manuela Beltrán.

## Cómo correr el proyecto

1. Clonar el repositorio
2. Crear entorno virtual: `py -m venv venv`
3. Activarlo: `venv\Scripts\activate`
4. Instalar dependencias: `pip install -r requirements.txt`
5. Copiar `.env.example` como `.env` y poner tu contraseña de PostgreSQL
6. Crear la base de datos `megasupply` en tu PostgreSQL local
